# Stress Test 동작 원리

실제 게임 클라이언트와 동일한 패킷 규격을 사용하는 가상 클라이언트를 여러 개 생성하여 서버에 부하를 발생시킵니다.

1. 모든 클라이언트를 한 번에 접속시키지 않고 Ramp 시간에 걸쳐 분산 접속합니다.
2. 각 클라이언트가 로그인과 `LoadingDone`을 완료한 뒤 실제 게임 상태로 진입합니다.
3. 클라이언트별로 이동 패킷과 Ping 패킷을 설정된 주기에 맞춰 전송합니다.
4. 서버는 수신한 이동 정보를 갱신하고 송신자를 제외한 전체 접속자에게 전파합니다.
5. Warm-up 구간에서 접속과 패킷 흐름을 안정화한 뒤 측정 구간의 결과만 성능 통계에 사용합니다.
6. Ping/Pong 왕복시간, 응답률, 패킷 처리량, 서버 CPU·메모리와 통신 오류를 1초 단위로 기록합니다.
7. 원본 측정값은 CSV로 저장하고, 결과 변조 여부를 확인할 수 있도록 SHA-256 해시와 시각화 보고서를 생성합니다.

동일 PC의 루프백 환경에서 서버와 부하 발생기를 함께 실행하면 측정값에 두 프로세스의 부하가 모두 포함됩니다. 따라서 결과에는 테스트 조건과 PC 사양을 함께 명시합니다.
